# ParkShare - Submission Upload Checklist

## Wait for Google Play

- Do not submit the final Devpost entry until v189 is approved or Google gives a clear response.
- If v189 is still pending close to the deadline, submit with the Alexa+ MCP server and explain that the Android build is under Google Play review.

## GitHub repo

- Create a repo named `parkshare-alexa-mcp-server`.
- Upload the full contents of `parkshare-alexa-mcp-server/`.
- Optionally include `parkshare-alexa-copilot-simulator/` as a companion visual demo folder.
- Keep `README.md`.
- Keep `LICENSE`.
- If public, select Open Source mini challenge.
- If private, share it with the Devpost/Amazon reviewers listed on the hackathon page when submitting.

## Devpost

- Project title: ParkShare Alexa+ Driving Copilot.
- Track: Alexa+.
- Demo video: public YouTube or Vimeo link, under 3 minutes.
- Repository: GitHub link for the MCP server.
- Description: copy from `parkshare_devpost_final_fields.md`.
- Product feedback: copy from `parkshare_devpost_final_fields.md`.
- Friction logs: copy from `parkshare_devpost_final_fields.md`.

## Demo video

- Record the simulator.
- Show the MCP server smoke test or terminal output briefly.
- Add 20-30 seconds of the real ParkShare app if v189 is approved.
- Speak in English or add English captions.
- Keep it under 3 minutes.
- Do not use copyrighted music.

## Last check before submit

- The project page must say "Alexa+ MCP server" as the main implementation.
- If showing the web UI, call it a companion simulator, not the main implementation.
- Do not claim production Alexa+ publication unless Amazon tooling is fully connected.
- Do not claim AWS Builder unless real AWS code was added.
- Do not claim Nebius/NVIDIA unless that version is actually built.
- Make sure every promised feature is visible in either the simulator, screenshots, or video.
